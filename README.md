# Manual QA, Defect Reporting and SQL Validation

A documentation and database-validation pack for a fictional e-commerce application.

## Files
- `test-cases.csv` — functional, negative, regression and accessibility scenarios.
- `sample-defects.md` — illustrative defect reports.
- `test-summary-template.md` — reusable execution summary.
- `sql/schema.sql` — PostgreSQL sample schema and synthetic data.
- `sql/validation_queries.sql` — reconciliation and integrity checks.
- `test-data-notes.md` — instructions for practicing with the data.

## How to use
1. Adapt test cases to a practice application and execute them.
2. Record actual outcomes and attach genuine evidence.
3. Replace hypothetical defect examples with issues you personally reproduce.
4. Run the SQL scripts in a local PostgreSQL database.

All data is synthetic. Never put customer, employer or client data in a public portfolio. Defects in `sample-defects.md` are hypothetical format examples, not claims about a real product.
